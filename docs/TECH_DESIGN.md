# Технический дизайн

## Слои

- `domain`: чистая детерминированная симуляция без Phaser и браузерных API.
- `application`: команды, игровые события и сохранения.
- `presentation`: Phaser-сцены, ввод, HUD, renderer и звук.

Симуляция обновляется фиксированным шагом 50 мс. Отрисовка выполняется каждый кадр и не владеет игровыми правилами.

## Правила зависимостей

- `domain` не импортирует Phaser.
- Случайность проходит через seeded RNG; `Math.random()` в домене запрещён.
- UI отправляет `GameCommand` и читает `RunState`.
- Системы публикуют `GameEvent` для эффектов и уведомлений.
- Сохранение скрыто за `SaveRepository`.

## Сохранения

`ProfileSave` содержит открытия и настройки. `RunSave` содержит версию и полный `RunState`. Автосохранение выполняется на рассвете; выход ночью возвращает к последнему рассвету.

Первая реализация использует `localStorage`. Electron-адаптер позднее использует каталог приложения без изменения домена.

## Сцены

`BootScene` → `MainMenuScene` → `RunSetupScene` → `GameScene` → `ResultsScene`; `MetaProgressionScene` открывается из меню и результатов.

## Presentation renderer

- AssetCatalog хранит ключи текстур, пути, игровые размеры и смещения ассетов.
- BootScene загружает зарегистрированные ассеты централизованно.
- WorldRenderer разделяет карту, мировые объекты и экранные overlays.
- Здания, жители, дружина, герой и враги сортируются по нижней координате Y.
- Для здания без готового изображения автоматически используется цветной placeholder из BUILDINGS.
- HUD остаётся в GameScene и всегда рисуется поверх мира.
