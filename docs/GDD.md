# GDD vertical slice

## Цикл забега

```text
Выбор героя и seed → развитие днём → подготовка в сумерках
→ атака Нави ночью → награда → босс пятой ночи
```

Время идёт непрерывно. Доступны пауза, скорость 1× и 2×.

## Экономика

| Ресурс | Назначение |
|---|---|
| Дерево | здания и ремонт |
| Камень | укрепления |
| Зерно | сырьё для еды |
| Еда | содержание жителей и дружины |
| Руда | сырьё кузницы |
| Оружие | наём дружины |
| Серебро | события и особые решения |

Цепочки: лесной двор → дерево; каменоломня → камень; поле → зерно → поварня → еда; рудник → руда → кузница → оружие.

Жители занимают рабочие места автоматически по приоритету `high`, `normal`, `low`; `disabled` останавливает здание. Доставка визуализируется, склад централизован.

## Контент

- Герой: Коловрат; способность «Клич рати» усиливает ближайших защитников.
- Дружина: ратник, лучник, волхв.
- Навь: упырь, мара, лешак и босс Морок.
- Здания: изба, лесной двор, каменоломня, поле, поварня, рудник, кузница, дружинный двор, вышка, обережный столб.
- Seed меняет бонусы участков, события, награды и состав волн.

## Итог забега

Разрушение ворот или гибель героя означает поражение. Гибель Морока на пятой ночи означает победу. Профиль сохраняет открытия, летопись и настройки, но не ресурсы и числовую силу.
