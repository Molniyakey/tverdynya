- [x] Новая структура продуктовой документации.

- [x] Профиль, сохранение забега и летопись.
- [x] Победа, поражение и контентные открытия без постоянной силы.
- [ ] Расширить события и реликвии после плейтеста ядра.

## M4 — Presentation 🔄

- [x] Меню, setup, game, meta и results scenes.
- [x] Каталог ассетов, слоистый WorldRenderer и сортировка объектов по Y.

- [x] Electron-конфигурация и Windows CI для portable build.

## Definition of Done

Пять дней проходятся за 20–30 минут, босс завершает забег, сохранение восстанавливает рассвет, игра держит 60 FPS при 30 союзниках и 100 врагах, typecheck/build/tests проходят в Docker.
